The call, and every argument it takes

If you have used meta, you have already met most of these

1

The one entry point

easypr.object.hr <- easypr(
    data       = ma$zhang,   # one row per study
    sm         = "HR",       # HR, OR, RR, cstat, OE
    method     = "Inverse",  # inverse variance
    method.tau = "REML",     # between-study variance
    method.ci  = "t",        # Knapp-Hartung, or "z"
    studlab    = "Study",    # or left out, and found
    level      = 0.95,        # both intervals
    common     = FALSE)      # show the fixed effect too
ArgumentWhat it doesDefault
dataA data frame. One row per study for a factor, one per validation for a model.required
smThe summary measure. It decides the columns, the scale, the units and the forest's columns."HR"
methodThe pooling. These measures arrive as an estimate and a standard error, so inverse variance is the only one there is, and any other is refused by name."Inverse"
method.tauEstimator for the between-study variance. Passed through to metamisc or metafor, so REML, DL, ML and the rest all work."REML"
method.ciHow the interval around the pooled estimate is built. "t" is the Knapp-Hartung adjustment, which the handbook recommends and which matters most when there are few studies; "z" is the normal interval."t"
studlabA column of labels, or a vector of them. Left out, easyPR looks for a column called Study.NULL
levelWidth of the confidence interval and of the prediction interval together.0.95
commonPrint the fixed-effect estimate beside the random-effects one.FALSE

There is no random to turn off. A prognostic review is summarised by a random-effects model and its prediction interval, so asking for the fixed effect alone is refused with that sentence.

The four that take what it returned

FunctionMain arguments
easypr_forest()x, label.e, label.c, direction, xlab, xlim, order, columns, prediction, digits, row.height, effect.width
easypr_loo()x, order, xlab, xlim, digits, result
easypr_metareg()x, moderator, main, xlab, ylab, result
easypr_funnel()x, main, xlab, levels, result

Every one of them also takes filetype, path, file.name, width and height. Name a file and the figure is written and the path reported. Leave it out and the figure is drawn on screen and nothing is saved. 

# drawn on screen, nothing written
easypr_forest(easypr.object.hr)

# written, and the size reported
easypr_forest(easypr.object.hr,
              file.name = "forest",
              path = "figures")
easypr: wrote figures/forest.png (7.75 x 8.37 inches)

result = FALSE keeps the console quiet when the figure is the only thing you want, which is what a chunk in a book or a slide usually wants.

3

What sm puts in the forest

The columns beside the effect are not a style choice. They are the quantities that measure is read against, so they follow sm without being asked for. A column your table does not carry is dropped rather than printed as a row of blanks.

smColumnsAxis
"HR", "OR", "RR"Study, N, HR, 95% CI, Weightratio ladder, 1 always labelled
"cstat"Study, N, Events, c, 95% CI, Weightc-statistic, spaced as the logit
"OE"Study, Observed, Expected, O:E, 95% CI, Weightratio ladder, 1 always labelled

columns = FALSE leaves the study label alone, and a character vector keeps the ones you name. A column of counts is totalled on the pooled row. Every column is centred but the study label, which is left.

One function fits, four draw. Nothing else is exported, and nothing takes a formula.
